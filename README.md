# أموالي | Amwali

تطبيق أندرويد شخصي لتسجيل الدخل والمصروفات والميزانية والتقارير، بواجهة عربية/إنجليزية، والعملة الأساسية الدينار العراقي (د.ع).

## المميزات

- لوحة رئيسية للرصيد وإجمالي الدخل والمصروفات.
- إضافة وحذف معاملات الدخل والمصروفات مع التصنيف والتاريخ.
- تحديد ميزانية ومتابعة المصروفات والتقارير حسب التصنيف.
- التبديل بين العربية (RTL) والإنجليزية (LTR).
- تخزين محلي على الجهاز باستخدام `SharedPreferences`.
- لا يطلب التطبيق إذن الإنترنت، ولا يتضمن SDK للإعلانات أو التحليلات.
- تعطيل النسخ الاحتياطي للنظام في بيان التطبيق.

## بناء APK تلقائيًا من GitHub Actions

1. أنشئ مستودعًا جديدًا على GitHub باسم `Amwali`.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، بحيث يظهر `settings.gradle.kts` و`app/` و`.github/` مباشرةً في الصفحة الرئيسية للمستودع.
3. افتح تبويب **Actions** في المستودع وفعّل GitHub Actions إذا طُلب منك ذلك.
4. سيبدأ البناء تلقائيًا عند رفع الملفات إلى فرع `main` أو `master`. ويمكنك تشغيله يدويًا من **Actions → Build Amwali Android APK → Run workflow**.
5. بعد نجاح التشغيل، افتح نتيجة التشغيل (workflow run)، ثم قسم **Artifacts** في أسفل الصفحة، ونزّل `amwali-debug-apk`.
6. فك ضغط الملف الذي نزلته لتحصل على `app-debug.apk`، ثم انقله إلى هاتف Android وثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

> ملف APK الناتج من هذا المسار هو **Debug APK** للتجربة والتثبيت الشخصي، وليس إصدارًا موقّعًا للنشر على Google Play.

## بناء محليًا

يتطلب Java 17 وAndroid SDK Platform 35 وGradle 8.9. من جذر المشروع نفّذ:

```bash
gradle --no-daemon assembleDebug
```

المخرج: `app/build/outputs/apk/debug/app-debug.apk`.

## الخصوصية

تُحفظ المعاملات محليًا على الجهاز. لا يحتوي بيان التطبيق على إذن `INTERNET`. حذف التطبيق يزيل بياناته الخاصة؛ لذلك احتفظ بنسخة خارجية من أي معلومات مهمة إذا احتجت إليها. لم يتم التحقق من التطبيق على جهاز فعلي بعد، ويُنصح باختباره قبل الاعتماد عليه في السجلات المالية المهمة.
